# Security

## Scope

This tool makes passive checks only: DNS lookups and normal web requests to the main site of a domain. It does not scan ports, guess passwords, fuzz or try to log in.

Only check domains you own or have permission to assess.

## Reporting a problem

If you find a security problem in this tool, please do not open a public issue. Use the "Report a vulnerability" button in the Security tab of this GitHub repository.

I will reply as soon as I can. This is a student project, so please be patient.
